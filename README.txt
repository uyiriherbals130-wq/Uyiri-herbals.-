# Uyiri Herbals Website

A responsive white + green herbal online-store starter website for GitHub Pages.

## Files
- index.html
- style.css
- script.js
- uyiri-logo.jpg

## Before publishing
1. Open `script.js`.
2. Replace `WHATSAPP_NUMBER` with your WhatsApp number (country code + number, no + or spaces).
3. Replace the sample products with your real product names, prices, descriptions and image filenames.
4. Put product images in the same folder.
5. Upload all files to a GitHub repository.
6. Enable GitHub Pages from Settings → Pages → Deploy from branch → main → /root.

Note: GitHub Pages hosts the front-end. Real payment processing, inventory/database and secure order management require a separate backend/payment service.
